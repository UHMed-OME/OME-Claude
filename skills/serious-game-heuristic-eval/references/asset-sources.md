# License-Friendly Asset Sources

Pair every asset recommendation with a concrete place to get it from a license-friendly
source, so a non-artist team can actually ship. Prefer, in order: **CC0 / public domain**
(no attribution, modify freely) → **permissive** (MIT/ISC/OFL/Apache, usually no
attribution in product) → **CC-BY** (free but requires credit). Avoid CC-BY-SA, CC-NC,
and "free for personal use only" for institutional/published work unless the team
accepts the terms.

**Always state the license in the asset list** and add a standing caveat: licenses
change, so verify the current terms per asset before shipping, keep a credits file for
any CC-BY/attribution assets, and confirm commercial/institutional use is permitted.

## Icons & UI (resource/status icons, buttons, HUD)
- **Game-icons.net** — 4,000+ game-flavored icons (hearts, brains, shields, herbs…).
  CC-BY 3.0 (credit required). Ideal for resource/token icons.
- **Lucide** (lucide.dev) — clean line icons, ISC license (no attribution). Pairs well
  with React builds.
- **Tabler Icons / Heroicons / Phosphor** — MIT, no attribution. Large, consistent sets.
- **Kenney.nl UI packs** — CC0. Buttons, panels, cursors, progress bars.

## Characters / avatars / people illustrations
- **Open Peeps, Humaaans, Open Doodles** (Pablo Stanley) — CC0. Mix-and-match characters;
  good for a state-reactive avatar.
- **unDraw** (undraw.co) — open-license illustrations, recolorable, no attribution; good
  for scene/spot art.
- **DrawKit / Blush** — some free CC0/permissive packs (check per pack).

## Scenes / backgrounds / spot illustration
- **unDraw**, **Kenney backgrounds** (CC0), **OpenGameArt.org** (filter to CC0/CC-BY).
- **Pixabay / Pexels** — photos/vectors under their free license (commercial OK, no
  attribution) if a photographic look is wanted.

## Mixed game-art libraries (sprites, tiles, FX)
- **Kenney.nl** — the gold standard: huge CC0 libraries of sprites, particles, UI, audio.
- **OpenGameArt.org** — large but MIXED licenses; always read the per-asset license.
- **itch.io asset packs** — many free/CC0 packs; license is per pack.

## Animation / juice
- **LottieFiles** — JSON animations; license varies per file (free + attribution tiers) —
  check each. Good for value pops and token-gain bursts.
- Hand-rolled CSS/JS for shakes, flashes, and number pops costs nothing and ships lightest.

## Audio (SFX, ambience, stings, music)
- **Freesound.org** — filter to CC0 (or CC-BY with credit). Huge SFX library.
- **Mixkit** — free SFX and music under the Mixkit license (commercial OK).
- **Kenney audio packs** — CC0 UI/game sound sets.
- **Pixabay audio** — free license, no attribution.
- **Sonniss "GDC Game Audio Bundle"** — large royalty-free SFX packs.

## Fonts
- **Google Fonts** — OFL/Apache, free for commercial use and embedding.

## Notes for AI-generated assets
If the team generates art/audio with an AI tool, record which tool and its output-usage
terms; some restrict commercial use or require a paid tier for ownership/commercial
rights. Keep generated assets consistent with the chosen style guardrail.
